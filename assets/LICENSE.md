# Происхождение ресурсов

Все PNG в этой папке созданы встроенным imagegen для проекта LUM по художественным референсам, предоставленным пользователем. Референсные листы сами не распространяются в архиве. Внешние стоки, шрифты и аудиотреки не использованы.

В составе проекта авторская графика распространяется по MIT вместе с кодом. Это разрешение распространять материалы этой сборки, а не заявление об исключительности AI-изображений или правах на исходные референсы. Для учебной сдачи укажите AI-происхождение ресурсов.

Звуки и короткая фоновая мелодия генерируются кодом `SoundManager.js` через Web Audio: записи сторонних авторов не используются. Начало аудио требует действия пользователя; доступны выключатель и громкость.

Промпты: `../ART.md` для первой версии и `GENERATION.md` для графики кампании.
